# Guitar NTE v1.0.0

首次公开发布，支持吉他 / 钢琴 36 音、MIDI 单文件及文件夹导入、文本谱、即时搜索、内容去重、可视预演、全局热键和输入权限预检。

## 下载

- `GuitarNTE-win-x64.zip`：Windows 10 / 11 x64 便携包，自带 .NET 10。
- `SHA256SUMS.txt`：ZIP 与 EXE 的 SHA-256。PowerShell 可使用 `Get-FileHash .\GuitarNTE-win-x64.zip -Algorithm SHA256` 核对。

完整解压后运行 `GuitarNTE.exe`。默认 F8 开始 / 暂停 / 继续，F9 急停。升级前关闭旧版并备份 `%LocalAppData%\GuitarNTE`。

本版本未进行代码签名，不包含私人曲库或第三方转谱媒体。游戏是否接收 SendInput、钢琴半音和复杂和弦的实际效果需在目标环境中确认；可视预演不会发送输入或播放音频。

完整操作与当前验证记录请见仓库 README、使用指南和 VALIDATION.md。
